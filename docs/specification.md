# 📄 Essential Recorder システム仕様書 (v1.0)

## 1. システム概要
本システムは、完全ローカル環境で動作する録音・文字起こし・重要事項抽出アプリケーションです。
外部のクラウドAPIを使用せず、デバイス内で音声データの処理からLLMによる要約までを完結させることで、機密性の高い会議や個人的なメモの安全な処理を実現します。

## 2. システム構成・アーキテクチャ
クライアント・サーバーモデルを採用し、UIとAI処理を分離します。

*   **フロントエンド (クライアント): `Flutter`**
    *   ユーザーインターフェースの提供、録音制御、バックエンドへのデータ送信、結果表示。
    *   対象プラットフォーム: Windows / macOS / (将来的にはAndroid / iOS)
*   **バックエンド (ローカルAPI): `Python` + `FastAPI`**
    *   音声データの受信、STT（音声認識）、LLMプロンプト処理。
*   **AIモジュール (バックエンド内)**
    *   **STTエンジン:** `faster-whisper` (ローカルでの高速な文字起こし)
    *   **LLMエンジン:** `Ollama` (要約、Todo抽出などの推論実行)
    *   **推論モデル:** `Qwen-2.5` または `Llama-3` 派生モデル（8Bクラスを想定）

## 3. 機能要件

### 3.1 録音・音声入力機能 (Flutter)
*   マイクからの音声録音開始・停止。
*   録音中のインジケーター（録音時間、波形アニメーション等）の表示。
*   録音した音声の一時的なローカル保存（WAV/M4A形式）。

### 3.2 AI処理連携機能 (Flutter ↔ FastAPI)
*   録音停止後、音声ファイルをバックエンドAPIへHTTP(POST)送信。
*   バックエンドでの処理中ステータス（「文字起こし中...」「要約中...」）の表示。

### 3.3 音声認識機能 (FastAPI)
*   受信した音声ファイルを `faster-whisper` でテキスト化（生ログ生成）。
*   無音部分の自動スキップ処理。

### 3.4 重要事項抽出機能 (FastAPI)
*   生成された生ログテキストを、特定のシステムプロンプトと共にローカルのOllama APIへ送信。
*   **プロンプト要件:** 「提供されたテキストから、(1)結論 (2)重要なポイント (3)具体的なTodoリスト を抽出し、Markdown形式で出力してください。」

### 3.5 結果表示・管理機能 (Flutter)
*   バックエンドから返却された「生ログ」と「重要事項（要約）」の画面表示。
*   結果データのローカルデータベース（SQLiteまたはShared Preferences）への保存と履歴一覧表示。
*   テキストのクリップボードへのコピー機能。

## 4. 非機能要件
*   **完全ローカル動作:** インターネット接続がない（オフライン）環境でも全機能が動作すること。
*   **プライバシー保護:** 音声データおよびテキストデータが外部サーバーへ送信されないこと。
*   **応答性能:** 録音終了から要約完了までの時間を、使用PCのスペック内で可能な限り最適化すること（FastAPIの非同期処理を活用）。

## 5. APIインターフェース仕様 (バックエンド)

### エンドポイント: `/api/v1/process-audio`
*   **メソッド:** `POST`
*   **リクエスト:**
    *   `Content-Type: multipart/form-data`
    *   `file`: 音声ファイルデータ (WAV/M4A等)
*   **レスポンス (正常時):** `200 OK`
    ```json
    {
      "status": "success",
      "raw_text": "本日は〇〇の件について...（文字起こしの全文）",
      "essential_summary": "## 結論\n...\n## Todo\n- [ ] 〇〇の資料作成\n..."
    }
    ```
*   **レスポンス (エラー時):** `400 / 500 Error`
    ```json
    {
      "status": "error",
      "message": "音声ファイルの処理に失敗しました。"
    }
    ```

## 6. 画面設計（UI/UX概要）

1.  **ホーム画面 (Home Screen)**
    *   画面中央に大きな「録音ボタン」。
    *   下部に過去の録音履歴リスト（日付、要約のプレビュー）。
2.  **録音中画面 (Recording Screen)**
    *   録音時間カウンター。
    *   「停止して要約」ボタン、「キャンセル」ボタン。
3.  **結果詳細画面 (Result Detail Screen)**
    *   上部: 抽出された重要事項（Essential）のMarkdown表示。
    *   下部: タップで展開できる文字起こし全文（生ログ）。
    *   「コピー」ボタン、「削除」ボタン。
